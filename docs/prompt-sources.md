# General prompt sources

The optional `plugins/prompt-manager/presets/general.md` is a portable working-rule preset. It contains no provider configuration, private endpoint or API key.

- OpenAI Codex v0.161.0, Apache-2.0: https://github.com/openai/codex
- Google Gemini CLI, Apache-2.0: https://github.com/google-gemini/gemini-cli
- OpenCode, MIT: https://github.com/anomalyco/opencode
- Superpowers, MIT: https://github.com/obra/superpowers
- ECC, MIT: https://github.com/affaan-m/everything-claude-code

Community excerpts cover root-cause investigation, testing one hypothesis at a time, evidence before completion, progressive retrieval, and KISS/DRY/YAGNI. Task completion, authorization and delivery rules come from the harness defaults. The small local compatibility section names the available shell and delegation contracts; it contains no local filesystem locations or credentials.
